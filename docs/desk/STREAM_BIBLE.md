# Stream Bible

The only live-video list. Hangar maintains the rows. Proof grades them. Verify before embed.

## Before an embed

1. Copy the channel or video ID from the operator. No YouTube search URL.
2. Pick the shelf. Do not guess the clock.
3. Proof watches the feed and writes CONFIRMED, LIKELY, WATCH, or KILL on the row.
4. Homepage `featured_stream` may use a row only after that grade. Verified 24/7 plus CONFIRMED is the only hero. If that shelf is empty, leave the player empty.

## Shelves

| Shelf | Rule | Embed? |

| Scheduled | Named show, named airport, operator-published days and times. | No hero. Link only inside the published window. |
| Highlights | Clip of a movement already graded CONFIRMED or LIKELY. | Not live. No clock. |
