# Source List

New sources are added here before they appear in a packet. Social is a tip wire. Primary documents beat aggregators.

Proof does not inherit a source just because a beat bot likes it. Proof may strike a source from a packet without striking it from this list.

## How to add a source

Fill every column. "Saw it on Twitter" is not a source. A named account plus a dated URL can be a tip.

| Class | Name | What it is good for | Use in public copy? | Notes |
|---|---|---|---|---|
| Primary | Airline investor / newsroom pages | Fleet orders, route launches, liveries the airline has announced | Yes, if the page is dated | Prefer the airline's own PDF or newsroom over a rewrite |
| Primary | Airport operator / NOTAM / AIS | Closures, runway work, visiting arrivals the airport has posted | Yes | Quote the airport, not a screenshot of a group chat |
| Primary | OEM (Airbus, Boeing, Embraer, Bombardier, Gulfstream, Dassault, ATR, etc.) | Deliveries, first flights, type news the OEM posted | Yes | Delivery tweets are tips until the OEM or operator page matches |
| Primary | Lessor / financier releases | Placements, teardowns, sale-leasebacks they announced | Yes | Do not infer the airline from a lessor photo alone |
| Primary | CAA / FAA / EASA / NTSB / AAIB / TSB | Registrations, airworthiness, accident records already published | Yes | Registration databases are facts about metal, not about passengers |
| Primary | Company filings (SEC, SEDAR, Companies House, AFM, etc.) | Fleet counts, capex, parked metal the filer named | Yes | Read the exhibit, not the headline |
| Trade | Cirium / FlightGlobal / Aviation Week / Leeham / ch-aviation (cited) | Context, not a CONFIRMED on their own | LIKELY ceiling unless a primary matches | Name the outlet. Do not launder a paywall rumor |
| Trade | Business Aviation / NBAA / EBAA / GAMA releases | Bizav hours, deliveries, show static | Yes when they are the publisher | Still 30% of the mix, not a second newspaper |
| Official data | ADS-B aggregators (adsb.fi, ADS-B Exchange, OpenSky) used as movement evidence | Type/reg/route already in the open | LIKELY at best for "it flew"; never for "who was aboard" | No public-figure jet from a track alone |
| Official data | Flightradar24 / FlightAware public pages | Same as above | LIKELY at best | Do not republish a track that only exists to find a person |
| Spotter | Airliners.net, JetPhotos, Planespotters.net *pages you can cite* | Livery, config, first photo of a tail | Supporting only | Credit the photographer if you use the fact of the photo |
| Scheduled video | Operator channel listed on STREAM_BIBLE.md | What the cam showed during a published window | Supporting | Never a search link |
| Tip wire | Named social posts, Discord, forums | Start a packet line as WATCH | No | Hand to Proof with the URL. Do not quote as fact |

## Standing exclusions

- Unnamed "industry sources" with no document.
- Tracker screenshots offered as proof that a named person travelled.
- Anything behind a login you do not have a right to use.
- Stolen manuals, leaked crew lists, blocked-number frequency logs tied to a person.

## First sources to keep bookmarked (public, no login)

Use these as the default wire. Add others as rows above when you actually cite them.

- Airline newsrooms and traffic notices (operator's own domain).
- Airport operator media pages (MAN, LHR, JFK, ATL, DXB, SIN, GRU, etc. as needed).
- FAA registry, CAA G-INFO, EASA, Transport Canada CCARCS.
- Airbus and Boeing monthly delivery/order pages.
- GAMA shipment reports; NBAA / EBAA newsrooms.
- NTSB, AAIB, TSB dockets already posted.
- Airliners Live channel page (Scheduled shelf only): https://www.youtube.com/@AirlinersLive

If a URL dies, blank the citation. Do not replace it with a search query.
