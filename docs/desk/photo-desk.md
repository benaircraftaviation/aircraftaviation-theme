# Photo desk

JSON key: `photo_desk`.

Replace, each week:

- `photo_of_the_day` — one image
- `left` — three images
- `right` — three images

Each photo needs `src`, `alt`, and `caption`. The caption has to describe that image. Credit the photographer when you have the name.

Use a page you can cite (Airliners.net, JetPhotos, Planespotters.net, or a photo already in hand). Do not hotlink a shot you cannot name.
